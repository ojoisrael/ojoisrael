### How I Approach Automation

I start with the business process rather than the tool.

**Identify the repetitive work → map the workflow → connect the systems → add AI where it creates value → automate the process → monitor and improve it.**

The goal is not simply to automate a task. It is to build workflows that are useful, understandable, and maintainable.
